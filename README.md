# 🚀 Portfolio Extraordinaire - Mouhamed-Aziz Mhamdi

Portfolio professionnel ultra-moderne et attractif d'un étudiant ingénieur à ESPRIT.

## ✨ Caractéristiques

### 🎨 Design & Animations
- **Design Dark Mode** élégant avec palette de couleurs vibrante
- **Animations fluides** et transitions sophistiquées
- **Particules interactives** sur canvas HTML5
- **Effets parallax** et animations 3D
- **Curseur personnalisé** avec effet de suivi
- **Glassmorphism** et effets de transparence modernes
- **Hover effects** impressionnants sur tous les éléments

### 🛠️ Technologies Utilisées
- HTML5 sémantique
- CSS3 avancé (Grid, Flexbox, Animations, Variables CSS)
- JavaScript ES6+ (Classes, Async/Await, Observers)
- Font Awesome 6.5.0 pour les icônes
- Google Fonts (Space Grotesk, Fira Code)

### 📱 Fonctionnalités
- **Responsive Design** - Compatible mobile, tablette et desktop
- **Navigation intelligente** avec indicateur de section active
- **Loader animé** au chargement de la page
- **Système d'onglets** pour les compétences
- **Filtres de projets** par catégorie
- **Compteurs animés** pour les statistiques
- **Barres de progression** animées pour les compétences
- **QR Code dynamique** généré automatiquement
- **Bouton "Retour en haut"** avec animation
- **Toast notifications** pour les feedbacks utilisateur
- **Easter eggs** cachés (Konami Code, triple-click logo)

### 🎯 Sections
1. **Hero** - Présentation avec effet de typing et badges flottants
2. **À propos** - Informations personnelles et statistiques
3. **Compétences** - Stack technique avec barres de progression
4. **Projets** - Portfolio de réalisations avec filtres
5. **QR Code** - Génération et téléchargement de QR code
6. **Contact** - Informations de contact
7. **Footer** - Liens et réseaux sociaux

## 🚀 Installation

1. Clonez ou téléchargez le repository
2. Ouvrez `index.html` dans votre navigateur
3. C'est tout ! Aucune dépendance à installer

## 🎨 Personnalisation

### Couleurs
Modifiez les variables CSS dans `style.css` :
```css
:root {
  --primary: #6366f1;
  --secondary: #ec4899;
  --accent: #14b8a6;
  /* ... */
}
```

### Contenu
- Modifiez le texte dans `index.html`
- Remplacez les images dans le dossier `image/`
- Ajoutez vos projets dans la section projets
- Mettez à jour vos liens sociaux

## 🌟 Fonctionnalités Avancées

### Curseur Personnalisé
Le curseur change d'apparence au survol des éléments interactifs.

### Particules Animées
Canvas HTML5 avec particules connectées qui bougent en arrière-plan.

### Effet de Typing
Le titre change automatiquement entre plusieurs rôles.

### QR Code Dynamique
Génération automatique d'un QR code pointant vers votre portfolio.

### Easter Eggs
- **Konami Code** : ↑ ↑ ↓ ↓ ← → ← → B A
- **Triple-click** sur le logo pour le mode disco

## 📱 Responsive

Le portfolio est entièrement responsive et s'adapte à :
- 📱 Mobile (< 768px)
- 📱 Tablette (768px - 992px)
- 💻 Desktop (> 992px)
- 🖥️ Large Desktop (> 1400px)
